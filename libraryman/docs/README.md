## Project Description
هذا نظام إدارة مكتبة رقمية بسيط تم تطويره بلغة جافا باستخدام مبادئ البرمجة الشيئية (التغليف، والوراثة، وتعدد الأشكال، والواجهات).

## How to Run
1. ترجمة الملفات عن طريق:
   javac src/libraryman/*.java -d comp
    
2. Run the application:
   java -cp comp libraryman.LibraryApp
##  Features
- Add Book
- Add Borrower       
- Borrow Book        
- Return Book        
- Search Book        
- Show Borrowed Books
- Exit
